# Molecular Visualization

This repository contains the molecular visualization files associated with Figure 2 of the manuscript.

## Figure 2A — Bleomycetin

The following files are provided for the predicted Bleomycetin–Trr1 docking complex:

- **`Figure_2A_Bleomycetin.pse`** — PyMOL session containing the predicted Bleomycetin–Trr1 docking complex and the molecular visualization used to generate Figure 2A.
- **`Figure_2A_Bleomycetin.png`** — Rendered molecular visualization used for Figure 2A.
- **`Bleomycetin_Trr1.pdb`** — Molecular coordinates of the predicted Bleomycetin–Trr1 docking complex.

Bleomycetin is represented as sticks. Selected predicted interacting residues are highlighted, while the catalytic residues **Cys145** and **Cys148** are shown separately for reference.

Dashed lines indicate selected predicted polar contacts, with interatomic distances reported in Å. These contacts are derived from the predicted docking pose and should not be interpreted as experimental evidence of direct target engagement.

## Software

Molecular visualization was performed using **PyMOL**.

## Reproducibility

The `.pse` file can be opened in PyMOL to interactively inspect the complete three-dimensional complex, including:

- the predicted ligand-binding pose;
- binding-site residues;
- catalytic residues Cys145 and Cys148;
- selected predicted polar contacts;
- interatomic distances; and
- alternative molecular orientations.

The corresponding `.pdb` file provides the molecular coordinates of the predicted docking complex and can be opened with other compatible molecular visualization and structural analysis software.
